How I work

The same path for every task, whether a person or an agent builds it.

  1. 11 Spec

    Spec

    Each task is a card with its acceptance criteria. The technical plan comes before the build.

  2. 22 Build

    Build

    A developer agent builds in its own workspace, with the design system and automatic checks.

  3. 33 Verify

    Independent verification

    A second agent checks every requirement with evidence. Failures go back and, if repeated, escalate.

  4. 44 Ship

    Review and ship

    I review at the end of each stage. Then it goes to staging, and from there to production.
